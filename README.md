# 🎮 Player Manager Dashboard

Real-time Roblox player monitoring system with automatic rejoin functionality.

## Features
- ✅ Live player tracking
- 🔴 Disconnect detection
- 🔄 One-click rejoin
- 📊 Real-time statistics

## Setup

1. Deploy to Vercel
2. Copy your Vercel URL
3. Update the Roblox script with your URL
4. Done!

## Usage
Players executing the script will appear in the "Live Players" section.
When they disconnect, they move to "Disconnected Players" where you can click REJOIN.
